# Radiora International: Medical Equipment Concept

A frontend concept for Radiora International, a fictional distributor of nuclear medicine, radiotherapy, PET tracer, health physics and radiology QA equipment. Built with Next.js 16 (App Router), TypeScript, Tailwind CSS v4, Motion, GSAP and Three.js.

Concept design by Zain Ali. Not affiliated with any real business.

## Run it

```bash
npm install
npm run dev
```

Then open http://localhost:3000.

## Pages

| Route | What it is |
| --- | --- |
| `/` | Hero, about, product lines, services, global reach, partners and contact |
| `/about` | Story, mission and vision |
| `/products` | Product explorer by domain, with 3D category models |
| `/services` | Consultancy, planning, installation, maintenance, repair and solution design |
| `/team` | Leadership |
| `/contact` | Contact details and a demo enquiry form |

## Content

The company, people, partner brands and contact details are fictional. Contact details are placeholders (for example `sales@radiora.example`). See `CREDITS.md` for image sources.
